## 🎮 Mini Games

Two fun mini-projects built using the concepts learned:

- **Guessing Number Game** – Guess the randomly generated number within a limited number of tries.
- **Reaction Time Test** – Tests how fast you can react to a visual prompt.

## 📚 Topics Covered

- **Basics** – Variables, Data Types, Operators, Input/Output
- **Control Flow** – Conditionals, Loops, Break/Continue
- **Methods** – Functions, Overloading, Exception Handling
- **OOP** – Classes, Objects, Constructors, Inheritance, Abstraction
